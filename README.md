# The One-Line Exit

A single-line resignation letter for the make.fun bounty "The One-Line Exit".
Exactly one line, 1–140 characters: a witness-protection relocation officer
hands in his notice — by disappearing himself.

Run `node main.ts` (Node stdlib only). It validates the line (one line,
1–140 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
